# Apple Music Remote (AMR) — Общий Роадмап проекта

Стратегический план развития высокопроизводительного нативного аудиофильского сервера и пульта дистанционного управления **Apple Music Remote (AMR)** для macOS.

---

## 🧭 Философия архитектуры AMR

1. **Бескомпромиссный Bit-Perfect звук**:
   - Прямое управление CoreAudio HAL без промежуточных программных микшеров и ресемплеров.
   - Жесткая аппаратная синхронизация частоты дискретизации ЦАП (44.1 – 192 кГц) в точном соответствии с исходным ALAC-потоком.
   - Принудительный 100% Volume Lock для исключения математической деградации разрядности (DSP truncation / dithering).
2. **Абсолютная автономность (Headless Mac mini)**:
   - Фоновая работа без графического окна и без использования ненадежных Accessibility GUI API.
   - Полное управление через нативный ScriptingBridge, AppleScript IPC и официальный Apple MusicKit REST API.
3. **Премиальный OLED UI и минимализм**:
   - Чистый монохромный веб-пульт с тактильным откликом, мгновенный скраббер 60fps с PLL-синхронизацией.
   - Roon-подобная визуальная прозрачность звукового тракта (Signal Path Inspector).

## 🎯 Ближайший релиз: v2.2.0 ("Chopin")
**Фокус:** Полноценное воспроизведение облачного каталога и результатов поиска без спонтанных переключений на посторонних исполнителей, переход на радио только в конце очереди, а также первые аудиофильские функции прозрачности тракта.

### 1. 🔀 Автономный фоллбек-контроллер очереди каталога (Single-Track Sequencing)
*Прямое управление очередью в памяти AMR без обязательной авторизации в Apple ID.*
- [ ] **Виртуальная очередь каталога в памяти (`activeCustomQueue`)**:
  - Фиксация всех 50+ треков из поиска в памяти AMR с поддержкой старта с любого трека.
- [ ] **Опережающий перехват окончания трека (Smart Auto-Advance)**:
  - Мониторинг таймкода в Music.app: за 1.5 секунды до конца трека (`pos >= dur - 1.5`) принудительная остановка плеера и моментальный запуск следующего трека из очереди поиска.
  - Music.app физически не успевает переключиться на встроенное радио смежных исполнителей (Korn, Linkin Park, Papa Roach).
- [ ] **Блокировка посторонних радио-треков**:
  - Исключение ошибочного подтверждения чужих треков в `QueueManager`: если Apple Music пытается включить радио-трек, AMR не подтверждает его, а сразу форсирует запуск целевой песни из очереди.
- [ ] **Корректная навигация Next / Previous в каталоге**:
  - Нажатие Next: мгновенный переход к следующему треку поиска.
  - Нажатие Prev: перемотка на 0:00 (если прошло > 3 с) или переход к предыдущему треку поиска.
  - Клик по любому треку в списке «Далее»: мгновенный прямой переход.
- [ ] **Переход на радио похожих исполнителей в конце очереди**:
  - Когда последний трек поиска доигрывает: автоматическое включение радиостанции исполнителя (`isRadioPlayback = true`, `Станция «Артист»`) и бесшовный переход к рекомендациям Apple Music.

### 2. 🔐 Интерактивная авторизация и синхронизация медиатеки (`Music-User-Token`)
*Добавление треков поиска во временный плейлист в iCloud через официальный Apple Music REST API.*
- [ ] **MusicKit JS в Веб-интерфейсе**:
  - Подключение `musickit.js` в веб-пульт AMR.
  - Кнопка *«Войти с Apple ID»* / *«Подключить Apple Music»* при первом запуске.
  - Интерактивный вызов `MusicKit.authorize()` через системный защищенный OAuth-диалог Apple ID.
- [ ] **Передача и безопасное хранение токена**:
  - Отправка `Music-User-Token` на Mac-сервер по WebSocket (`action: set_user_token`).
  - Сохранение токена в защищенном локальном хранилище сервера.
- [ ] **Управление временным облачным плейлистом**:
  - Создание плейлиста `Очередь AMR (Временная)` через REST API (`POST https://api.music.apple.com/v1/me/library/playlists`).
  - Пакетное наполнение треками из результатов поиска каталога.
  - Ожидание облачного push-уведомления в macOS Music.app и запуск воспроизведения через `library playlist`.
- [ ] **Автоматическая очистка**:
  - Удаление или очистка временного плейлиста после завершения воспроизведения очереди поиска.

### 3. 🎛 Аудиофильские функции v2.2 (Audiophile Quick-Wins)
- [ ] **Roon-like Signal Path Inspector v1**:
  - Интерактивная модальная карточка пути сигнала при клике на бейдж аудиокачества (Lossless / Hi-Res).
  - Детализация тракта:
    `[Source: Apple Music ALAC 24-bit/192kHz]` ➔ `[AMR CoreAudio Engine (Direct / 0 dB FS)]` ➔ `[DAC: Chord Mojo 2 / Topping / Schiit (Hardware Lock 192 kHz)]`.
  - Индикатор верификации Bit-Perfect (гарантия отсутствия системной передискретизации и DSP).
- [ ] **Дистанционный селектор ЦАП в Web UI**:
  - Выпадающий список подключенных аудиоустройств macOS прямо в веб-интерфейсе.
  - Мгновенное переключение активного ЦАПа через CoreAudio HAL API без подхода к Mac.
  - Hotplug-детектирование: автоматическое обновление списка устройств при подключении/отключении USB-ЦАПа.

## 🎻 Релиз v2.3.0 — «Bach» (Audiophile Precision & Queue Mastery)
**Фокус:** Монопольный аудиофильский режим CoreAudio, синхронизированные тексты песен и расширенные манипуляции очередью.

### 1. 🔒 CoreAudio Exclusive Mode / Hog Mode
- [ ] **Аппаратный монопольный захват ЦАПа (`kAudioDevicePropertyHogMode`)**:
  - Захват ЦАПа процессом AMR во время воспроизведения: полное отключение системных звуков macOS (оповещения, почта, щелчки интерфейса), подмешивающихся в аудиопоток.
  - Автоматическое освобождение ЦАПа при паузе или остановке для доступа других приложений.

### 2. 📑 Полноценный менеджер очереди (Queue Reordering & Batch Actions)
- [ ] **Drag-and-Drop перетаскивание треков**:
  - Сенсорное и мышиное перетаскивание треков в списке «Далее в очереди» в веб-интерфейсе.
  - Свайп влево по треку — быстрое удаление из очереди.
- [ ] **Контекстные действия (Play Next / Play Last)**:
  - Долгое нажатие или меню (⋯): *«Воспроизвести следующим»*, *«В конец очереди»*, *«Создать радио по треку»*.

### 3. 🎤 Синхронизированные тексты песен (Time-Synced Lyrics)
- [ ] Интеграция парсера построчных и слоговых текстов Apple Music / Musixmatch / открытых LRC-баз.
- [ ] Анимированный караоке-экран в веб-плеере с автопрокруткой и подсветкой текущей строки синхронно со скраббером 60fps.
- [ ] Мгновенный переход (`seek`) по клику на любую строчку текста.

### 4. ⚡️ Высокоскоростной дисковый кэш обложек
- [ ] Локальный LRU-кэш обложек альбомов на Mac в разрешении до 1200x1200px с отдачей WebP для экономии трафика.
- [ ] Мгновенная отрисовка в веб-интерфейсе при медленном мобильном Wi-Fi.

## 🎺 Релиз v2.4.0 — «Brahms» (Living Room, StandBy & Multi-Room Stream Relay)
**Фокус:** Большие экраны (iPad на стойке, ТВ), сетевая трансляция несжатого звука на стримеры и совместное прослушивание.

### 1. 🔀 Прямой стриминговый мост (Lossless Stream Relay)
- [ ] **Трансляция несжатого звука по локальной сети**:
  - Передача аудиопотока с Mac по протоколам FLAC / LPCM на сетевые аудиофильские транспорты и стримеры (WiiM Pro/Ultra, Bluesound Node, Sonos, Volumio, Moode Audio).
  - Сохранение бескомпромиссного аудиофильского качества для внешних стримеров без использования сжатия.

### 2. 📺 StandBy / TV / Ambient Mode (Режим гостиной)
- [ ] **Крупный интерфейс для iPad и экранов ТВ**:
  - Огромная обложка альбома, читаемая с нескольких метров типографика, время трека и бейдж ЦАПа.
  - **Динамический градиентный фон**: плавные переливы доминирующих тонов обложки трека в темной гамме (в стиле Apple Music на tvOS).
  - **Винтажные аналоговые VU-метры**: опциональные стрелочные индикаторы уровня громкости в реальном времени.

### 3. 👥 Party Mode (Гостевой доступ по QR-коду)
- [ ] Гостевой интерфейс по сканированию QR-кода: поиск и добавление треков в общую очередь с голосованием.
- [ ] Жесткая защита: гости не могут изменять громкость, переключать ЦАП или останавливать воспроизведение.

### 4. 📡 Управление выводом AirPlay 2
- [ ] Роутинг аудиопотока на дополнительные зоны (HomePod, Apple TV) прямо из веб-пульта.
- [ ] Раздельное управление громкостью для вторичных AirPlay-зон без нарушения 100% Bit-Perfect на основном USB ЦАП.

## 🏛 Релиз v3.0.0 — «Goethe» (Next-Gen Ecosystem & Audiophile Room DSP)
**Фокус:** Мажорная мобильная экосистема, точная коррекция акустики помещения и интеграции умного дома.

### 1. 📱 Нативное мобильное приложение для iOS / iPadOS / watchOS
- [ ] Клиент на **SwiftUI** с нулевой задержкой отклика.
- [ ] Поддержка **Live Activities** и Dynamic Island на iPhone.
- [ ] Управление воспроизведением с Apple Watch (включая плавную регулировку цифровой коронкой Digital Crown).
- [ ] Нативные виджеты для рабочего стола и экрана блокировки iOS.

### 2. 🎛 Аудиофильский Room Correction DSP (Опциональный PEQ)
- [ ] **Параметрический эквалайзер (PEQ)** на базе `AudioUnit` / `Accelerate.framework` для точечной компенсации комнатных акустических мод и стоячих волн.
- [ ] **Прямой импорт из Room EQ Wizard (REW)**: загрузка файлов фильтров коррекции акустики помещения.
- [ ] **Аппаратный Bit-Perfect Direct Bypass**: при отключенном EQ аудиотракт остаётся на 100% чистым и побитово точным.

### 3. 🌐 Spatial Audio & Headphone Enhancement Indicator
- [ ] Распознавание и мониторинг форматов Apple Spatial Audio / Dolby Atmos / ALAC Hi-Res 24-bit/192kHz.
- [ ] Профили согласования для наушников и внешних многоканальных аудиопроцессоров.

### 4. 🏠 Интеграции экосистемы
- [ ] **Официальная карточка Home Assistant (HACS Lovelace Card)**: интеграция в панели управления умным домом с поддержкой частоты ЦАП и обложек высокого разрешения.
- [ ] **Raycast & Alfred Extension**: управление треками, переключение ЦАП и поиск по каталогу из поисковой строки macOS.
