# Apple Music Remote (AMR) — Общий Роадмап проекта

Стратегический план развития высокопроизводительного нативного аудиофильского сервера и пульта дистанционного управления **Apple Music Remote (AMR)** для macOS.

---

## 🧭 Философия архитектуры AMR

1. **Бескомпромиссный Bit-Perfect звук**:
   - Прямое управление CoreAudio HAL без промежуточных программных микшеров и ресемплеров.
   - Жесткая аппаратная синхронизация частоты дискретизации ЦАП (44.1 – 192 кГц) в точном соответствии с исходным ALAC-потоком.
   - Принудительный 100% Volume Lock для исключения математической деградации разрядности (DSP truncation / dithering).
2. **Абсолютная автономность (Headless Mac mini)**:
   - Фоновая работа без графического окна и без использования ненадежных Accessibility GUI API.
   - Полное управление через нативный ScriptingBridge, AppleScript IPC и официальный Apple MusicKit REST API.
3. **Премиальный OLED UI и минимализм**:
   - Чистый монохромный веб-пульт с тактильным откликом, мгновенный скраббер 60fps с PLL-синхронизацией.
   - Roon-подобная визуальная прозрачность звукового тракта (Signal Path Inspector) и полноформатные цифровые буклеты с разбором каждой композиции.

## 🔗 Архитектурные цепочки зависимостей релизов

Все запланированные функции разложены строго последовательно от базовых примитивов к сложным производным системам:

1. **Мастеринг-телеметрия $\rightarrow$ Ночная динамика $\rightarrow$ Компаратор изданий $\rightarrow$ Слепой A/B тест**:
   - `v2.6.0` внедряет потоковый расчёт **`TT DR Meter`**, **`LUFS / True Peak`**, **`4x ISP`** и **`Phase Correlation`**.
   - `v2.8.0` использует `Short-Term LUFS / True Peak` для **`Ночного выравнивания тихих и громких пассажей`**.
   - `v2.9.0` использует накопленные индексы `DR` и частот в фасетном конструкторе **`Roon Focus`**.
   - `v2.12.0` использует `TT DR Meter + SpectralIntegrityAnalyzer` для автоматического сравнения релизов в **`Master Edition Comparator`**.
   - `v3.1.0` объединяет `Master Edition Comparator` и выравнивание `0.1 LUFS` в лабораторном **`Level-Matched Blind A/B & ABX Comparator`**.
2. **Акустический замер микрофоном iPhone/iPad $\rightarrow$ Студийный 64-bit Room DSP $\rightarrow$ Целочисленный 2x/4x апсемплер**:
   - `v2.7.0` внедряет **`1-Minute Room Acoustic Snapshot`** прямо из PWA (замер АЧХ комнаты, стоячих мод `20–200 Hz` и `RT60` микрофоном iPhone/iPad с паспортом комнаты в «Тракте сигнала»).
   - `v3.0.0` запускает **`CoreAudio Exclusive Hog Mode`** и **64-битный `Convolution FIR & PEQ` движок**, который напрямую применяет снятый в `v2.7.0` профиль комнаты для автоматической коррекции мод.
   - `v3.1.0` поверх монопольного тракта `Exclusive Hog Mode` добавляет **`Synchronous 2x/4x Integer Upsampler (16k-tap)`**, **`Personal Audiogram EQ`** и **`Reference Acoustic Suite`**.
3. **Очередь Linn Kazoo & Дизлайки $\rightarrow$ Профиль вкусов $\rightarrow$ Sonic Bridge $\rightarrow$ Граф знаний $\rightarrow$ Матрица Классики**:
   - `v2.6.0` создаёт мутации очереди **`Linn Kazoo`**, маркер **`Stop After Current`**, **`DislikedTracksStore`** и кликабельные кредиты в **`Интерактивном буклете`**.
   - `v2.7.0` опирается на `DislikedTracksStore` и очередь для построения **`CloudTasteProfileService`**, **`Waveform Seekbar`**, **`Up Next`** и **`Party Mode`**.
   - `v2.8.0` использует `CloudTasteProfileService` и 512-D эмбеддинги для построения геодезических маршрутов **`Sonic Bridge`** и неделимых связок **`Multi-Part Work Grouping`**.
   - `v2.11.0` сводит кредиты буклетов (`v2.6.0`) и акустические паспорта (`v2.6.0–v2.8.0`) в SQLite-граф **`Sonic Object Graph`** и запитывает от него **`Живое Радио-Шоу / ИИ-Конферансье`**.
   - `v2.12.0` и `v3.2.0` используют `Sonic Object Graph` для **`Сканера виниловых конвертов`** и **`Матрицы исполнений Классики и Джаза (Composer / Work / Recording Matrix)`**.
4. **Сетевые рендереры $\rightarrow$ Буфер `Memory Play` $\rightarrow$ Фазосинхронный мультирум**:
   - `v2.9.0` добавляет стриминг на **`ESPHome (I2S)`** и **`WiiM / UPnP AV (FLAC / LPCM)`**.
   - `v2.10.0` вводит невытесняемый буфер **`Zero-Jitter RAM Buffer (Memory Play)`**, **`Per-Device Volume Memory`** и **`Safe Startup Volume`**.
   - `v2.12.0` использует `Memory Play` для точной фазовой синхронизации всех рендереров в **`AMR SyncGroup`**.

  - Опираясь на связи `Composition ↔ Performance` в графе `Sonic Object Graph` (`v2.11.0`), кнопка **«🎻 Другие исполнения этого произведения»** на любом треке или в буклете находит все знаковые записи этой же симфонии, сонаты или джазового стандарта в каталоге Apple Music (с сортировкой по году записи, дирижёру/солисту, лейблу и индексу `DR`).

### 2. 💿 «Виниловый ритуал» и режим прослушивания альбома целиком (`Album-First / Vinyl Side A & Side B Mode`)
- [ ] **Режим вдумчивого прослушивания пластинки без клиповой суеты**:
  - Разбивка альбома на оригинальные стороны винила и диски (`Side A / Side B / Disc 1 / Disc 2`), опциональная пауза между сторонами пластинки и автоматический разворот полноэкранного Цифрового буклета.

### 3. 🎛 Классические стрелочные индикаторы уровня (`McIntosh / Nagra Analog VU Meters + Peak Hold`) на ТВ и планшете
- [ ] **Эталонная баллистика стрелочных индикаторов по стандарту IEC 60268-17**:
  - Переключатель визуализатора в режиме **StandBy / TV Mode** и плеере (`32-Band RTA ↔ Analog VU Meters`): отрисовка пары левого и правого стрелочных индикаторов уровня (`dBVU` / `dBFS`) с истинной физикой инерции стрелки (300 мс интеграция / 300 мс возврат) и пиковыми светодиодами перегрузки (`Peak Hold`) в винтажной/студийной эстетике *Nagra / McIntosh / Technics*.

### 4. 🕯 Режим «Полная темнота для критического прослушивания» (`Zero-Photon / Pitch-Black OLED & WLED Blackout Mode`)
- [ ] **Отключение паразитной засветки комнаты для максимального фокуса на 3D-сцене**:
  - Кнопка **«🌑 Тёмный зал (Blackout)»** на ТВ и планшете: гасит подсветку `WLED DDP` в `0` и переводит экран ТВ/OLED-планшета в `99.5%` абсолютный чёрный цвет (`#000000`), оставляя только едва заметную тёмно-янтарную нить прогресса и микро-подпись трека (с мгновенным пробуждением по касанию или пульту).

### 5. 📡 Внешний API и виджеты для аппаратных мини-дисплеев (`Now Playing Webhook / Matrix / E-Ink / StreamDeck API`)
- [ ] **Открытый JSON/WebSocket интерфейс и ультра-компактный экран для внешних дисплеев стойки**:
  - Публичный эндпоинт `/api/v1/now-playing` и `/api/v1/signal-path` + специальный высококонтрастный скин для малых 5–7" экранов у аудиостойки (Raspberry Pi / ESP32-S3, *Elgato StreamDeck*, E-Ink рамок) с отображением обложки, частоты ЦАПа, `DR`-индекса и стрелок `VU Meter`.
