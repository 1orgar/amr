# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in **Apple Music Remote (AMR)** a welcoming, respectful, and constructive engineering experience for everyone—whether discussing bit-perfect CoreAudio internals, DAC measurements, DSP algorithms, or UI ergonomics.

## Standards

- Focus on technical merit, reproducible measurements, and clear communication.
- Respect differing hardware setups (USB DACs, R2R NOS ladders, Sigma-Delta modulators, BluOS/DLNA streamers, and integrated amplifiers).
- Harassment, personal attacks, trolling, or publishing others' private information is not tolerated.

## Enforcement

Project maintainers may edit, lock, or remove contributions that violate this Code of Conduct. Report unacceptable behavior via GitHub to `@1orgar`.
