**Apple Music Remote (AMR)** — высокопроизводительный нативный сервер и пульт дистанционного управления для **Apple Music** на macOS. Создан специально для аудиофилов и ценителей качественного звука: воспроизведение идёт напрямую с вашего Mac через аппаратный ЦАП (DAC), обеспечивая честный **Bit-Perfect** вывод звука без системной передискретизации и потери качества.

## ✨ Ключевые возможности

### 🎧 Bit-Perfect аудиофильский вывод (CoreAudio)
* **Аппаратная синхронизация частоты ЦАП**: автоматическое переключение частоты дискретизации внешнего ЦАП (44.1, 48, 88.2, 96, 176.4, 192 кГц) в точном соответствии с исходным качеством трека в Music.app.
* **Режим Bit-Perfect 100%**: фиксация громкости macOS на 100% для исключения цифрового дизеринга и математической деградации разрядности звука (DSP truncation).
* **Пре-инспекция формата, Strict Format Lock и детекция AAC vs ALAC**: предварительный анализ параметров аудиопотока (`sampleRate` и `bitDepth`), строгая блокировка формата во время звучания трека и честное распознавание сжатого AAC (`16-бит / 44.1 кГц`, индикатор Lossy) против ALAC Lossless / Hi-Res (`24-бит / до 192 кГц`).
* **Спектральный БПФ-верификатор Hi-Res (`SpectralIntegrityAnalyzer`, `vDSP`)**: 4096-точечный БПФ-анализ с окном Ханна и проверка младших разрядов (`LSB Bit Depth`) напрямую из PCM-потока для разоблачения апсемплинга (`TRUE HI-RES`, `FAKE HI-RES • 22K CUT`, `UPSAMPLED 48K`, `16-BIT PADDED`, `CD LOSSLESS`) прямо в модальном окне «Тракт сигнала» с персистентным двухуровневым кэшированием результатов для локальных (`persistentID`) и облачных (`catalogId`) треков.
* **DAC Muting Guard & Click-Free Switcher**: опциональная трёхфазная бесщелчковая защита при переключении частоты дискретизации внешнего ЦАП (*Pre-Mute → Clock Lock → Unmute*).
* **Интерактивный тракт сигнала (Signal Path)**: наглядная схема всей цепочки аудиосигнала в стиле Roon: Источник (кодек, битность, частота дискретизации), Спектральный верификатор, Движок AMR (`0.0 dB FS`, Zero DSP, обход микшера) и активный выходной ЦАП или стример BluOS.
* **Переключение ЦАП и BluOS прямо из веб-пульта**: быстрый выбор любого подключенного аудиовыхода, внешнего ЦАП или сетевого стримера BluOS без принудительного автостарта воспроизведения в состоянии паузы.
* **Опциональный регулятор громкости, мост внешнего усилителя по TCP (`ExternalAmpTCPController`) и аппаратная Bit-Perfect нормализация (`AppleSoundCheckService`)**:
  * Если фиксация 100% громкости выключена, в веб-плеере доступен программный регулятор громкости.
  * При включённой фиксации громкости Mac 100% (*Bit-Perfect*) во вкладке **«Усилитель»** можно активировать прямое управление громкостью внешнего усилителя или ресивера по текстовым TCP-сокетам (**Rotel `:9590`**, **Denon / Marantz `:23`**, **Hegel `:50001`**, **NAD `:30000`**, **Lyngdorf `:84`**) с фоновым опросом громкости с пульта ДУ, настраиваемым лимитом максимальной громкости (`1–100%`), аппаратной защитой от скачков в `0` и `100%`, проверкой соединения, отображением узла `УСИЛИТЕЛЬ` в окне «Тракт сигнала» и регулировкой на ТВ (слайдер на уровне кнопок, свайп вверх/вниз по экрану и зум-лупа с процентами).
  * **Аппаратная Bit-Perfect нормализация громкости треков (`AppleSoundCheckService` + умная нелинейная нормализация на низкой громкости)**: извлекает официальные метаданные `iTunNORM` из локальных файлов и `.m4a`-заголовков каталога Apple Music (а для треков без тегов рассчитывает перцептивную громкость `ITU-R BS.1770` в реальном времени через `SpectralIntegrityAnalyzer`) и автоматически компенсирует разницу мастеринга напрямую аттенюатором внешнего усилителя по TCP при сохранении 100% Bit-Perfect вывода CoreAudio (`0.0 dBFS`). Включает переключаемую опцию **«Умная нормализация на низкой громкости (< 40%)»**, адаптированную под нелинейную характеристику аттенюаторов усилителей (Rotel и др.) и кривые равной громкости слуха на тихих уровнях.
* **Индикатор ЦАП в реальном времени**: постоянный бейдж качества аудиопотока и частоты ЦАП во всех представлениях интерфейса (в шапке Now Playing, на десктопе и на смартфонах).

### 📺 Режим гостиной StandBy / TV Mode, 📊 32-полосный RTA и 🌈 подсветка WLED DDP
* **Полноэкранный режим StandBy / TV Mode**: крупная обложка альбома, поддержка живых видео-обложек **Apple Music Motion Covers** (HLS), читаемая с нескольких метров типографика, динамический Ambilight-фон и автоматическое запоминание выбранного режима в сессии браузера.
* **32-полосный RTA-анализатор спектра в реальном времени**: переключатель `RTA` в TV-режиме открывает 60fps логарифмический анализатор спектра (`20 Гц – 96 кГц`) с выделением слышимого диапазона и ультразвуковой зоны Hi-Res (`> 22.05 кГц`).
* **Полноэкранная Медиатека в TV-режиме**: кнопка **«Медиатека»** открывает полноэкранную сетку с вертикальной прокруткой и большими квадратными плашками (1:1) персональных станций («Моя станция», «Станция открытий», «В моём вкусе», «Сейчас на повторе») и всех локальных плейлистов медиатеки.
* **Аппаратная музыкальная подсветка WLED по протоколу DDP (порт 4048 UDP)**: прямой стриминг 16-зонной палитры обложки (`< 2 мс`, 40 FPS, гамма `γ = 2.4`) и 5 аудио-реактивных режимов в реальном времени от `AudioProcessTapService` (*«Синусоида ритма»*, *«Спектральный эквалайзер Бас·Вокал·Верх»*, *«Симметричный пульс VU»*, *«Гармонический резонанс»*, *«Статичная палитра обложки»*), а также мягкое затухание на паузе и фоновый Heartbeat OFF.

### 📖 Цифровые буклеты альбомов и полный гид по композициям (`DigitalBookletService` + `PDFKit`)
* **Многостраничный интерактивный ридер**: последовательные страницы вместо правой панели на Desktop / Tablet Landscape и полноэкранный режим на TV / Mobile Portrait.
* **История записи, гид по трекам и студийные кредиты**: редакционные эссе Apple Music + многоязычный фоллбек *Wikipedia (RU / EN)*, разбор каждой композиции альбома, полный перечень сессионных музыкантов, инструментов, продюсеров, звукоинженеров и авторов, а также нативный рендеринг локальных `.pdf` буклетов через `PDFKit`.

### 📡 BluOS & Сетевой стриминг (Lossless Stream Relay)
* **Прямой перехват аудиопотока (`AudioProcessTapService`)**: нативный перехват звука Music.app через CoreAudio Process Tap API (`AudioHardwareCreateProcessTap`) на macOS Sonoma/Sequoia без виртуальных кабелей, без изменения системного устройства вывода и без приглушения звука Mac.
* **Bit-Perfect стриминг на BluOS**: передача чистого LPCM / WAV до 192 кГц / 24-бит Hi-Res Lossless (и честных 16-бит / 44.1 кГц для сжатого AAC) напрямую на Bluesound (NODE, POWERNODE) и совместимые сетевые рендереры BluOS.
* **Двусторонняя синхронизация транспорта**: мгновенная синхронизация воспроизведения (Play, Pause, Seek, Volume) между физическим пультом/приложением BluOS и веб-пультом AMR.

### 📱 Премиальный веб-интерфейс (PWA) и персонализация Apple Music
* **Персональные рекомендации, станции и миксы**: полная поддержка раздела «Слушать сейчас» (`GET /v1/me/recommendations`), персональных радиостанций и еженедельных миксов с индивидуальными живыми **60fps SVG/CSS-плашками** («Моя станция», «Станция открытий», «В моём вкусе», «Сейчас на повторе», «Новинки для вас», «Чилл-микс», «Драйв-микс», «Микс для друзей», станции по артистам).
* **OLED-монохромный дизайн**: глубокий черный `#000000`, плавные аппаратные анимации, акцент только на обложках альбомов. Никакого визуального шума.
* **Отзывчивое управление и Zero-Stall Poller**: мгновенный отклик кнопок Play/Pause, двухконтурный легковесный IPC-опрос (~15 мс), быстрое двойное нажатие для перехода к предыдущему треку, поддержка клавиши Пробел на десктопе.
* **Надежная очередь облачных альбомов и поиска**: полная постановка всех треков облачных альбомов и плейлистов в очередь с учетом региональной витрины Apple ID без обрыва после 1-го трека и без сваливания в радио; автоматическая очистка временных плейлистов в фоне.
* **Высокоскоростной дисковый кэш обложек (`ArtworkDiskCache`)**: двухуровневое кэширование (память + персистентный диск LRU) для моментальной загрузки обложек альбомов.
* **Автоопределение Apple ID и региона**: автоматическое получение активного регионального стора (`us`, `ru` и др.) из настроек macOS Music, аккуратный статус аккаунта в шапке.
* **Дедупликация каталожного поиска**: умная фильтрация дублирующихся треков из расширенных/переизданных версий альбомов.
* **Сенсорные жесты**: свайп по обложке влево/вправо для переключения треков, свайп вниз для сворачивания полноэкранного плеера Now Playing в плавающий мини-плеер.
* **Скраббер 60fps**: локальная оптимистичная шкала времени с фазовой подстройкой (PLL) для идеально плавного движения таймкода без скачков и лагов.
* **Радиостанции в один клик**: создание персональных станций Apple Music по текущему треку или артисту прямо из плеера (📡).
* **Синхронизация «Избранного»**: добавление треков в избранное («Любимые песни») Apple Music со звездочкой и тактильным откликом.
* **Тренды, Чарты, Плейлисты и сохранение очереди в Медиатеку**: просмотр треклиста любых плейлистов каталога и медиатеки, кнопка **«+ В медиатеку»** для сохранения любого каталожного или персонального плейлиста, а также кнопка **«+ В плейлист»** в шапке Очереди для сохранения активной очереди или бесконечной ИИ-волны в новый плейлист Apple Music.
* **Авторизация клиентских устройств (PWA Device Auth), QR-шаринг доступа и индивидуальный Lock Screen (`ClientDeviceManager`)**: генерация постоянного UID устройства (`HTTP Cookie` + `localStorage` + `CacheStorage`) с подтверждением новых клиентов из настроек macOS (до проверки Apple ID), персональное окно настроек каждого девайса в macOS и модальное окно `AMR v2.5.0` в стиле Signal Path (с последним Git-коммитом, кнопкой **«Поделиться доступом (QR)»** `?invite=<token>` для мгновенной авторизации по камере и переключателем экрана блокировки / Dynamic Island `MediaSession`).
* **Двуязычная локализация интерфейса (`RU / EN`) и адаптация под экраны iPhone**: автоматическое переключение Web UI и нативного macOS-приложения на английский язык для устройств с нерусской локалью, а также защитная черная полоска `safe-area` под кнопками разделов на iPhone.
* **Нативные функции ИИ на Apple Neural Engine (`NativeMusicCuratorService` + `ArtworkService` — `FoundationModels`, `NaturalLanguage` 512-D, `Vision` Saliency)**: управляются единым переключателем **«Нативные функции ИИ (Apple Neural Engine)»** в основных настройках macOS (на процессорах Intel `x86_64` тумблер автоматически скрывается, а ИИ-функции выключаются). Включают семантический **Промпт-Куратор** (`✨ AI Подбор` в Поиске и монохромное **ИИ-облако тегов** в режиме **StandBy / TV Mode**), **бесконечную ИИ-волну** с фоновой автоподгрузкой новых треков без повторов, **семантический поток очереди («Плавный поток» `NLEmbedding`)**, **«✨ ИИ-подбор по треку»** в меню `•••` и на ТВ, **закрепление любимых ИИ-вайбов (`★ Избранные вайбы`)** и **нейросетевую палитру обложек `Vision` Saliency (`VNGenerateAttentionBasedSaliencyImageRequest`)** для фонового свечения ТВ и 16-зонной ленты WLED DDP.

### 📻 UPnP / DLNA MediaRenderer (Интеграция с Home Assistant)
* Полноценная поддержка протокола **UPnP A/V MediaRenderer (AVTransport / RenderingControl)**.
* Автоматическое обнаружение через **SSDP Discovery** в локальной сети.
* **Отключаемый локальный MediaRenderer**: переключатель в окне Настроек и меню приложения для полного отключения локального UPnP-рендерера при использовании сетевых проигрывателей (BluOS) или Home Assistant.
* Поддержка интеграции с **Home Assistant**, умными колонками и DLNA-контроллерами: воспроизведение, пауза, остановка, перемотка, регулировка громкости.
* Встроенная поддержка приглушения звука (Audio Ducking) для голосовых ассистентов.

### 🍏 100% Нативное приложение macOS (Menu Bar)
* Написано полностью на **Swift** с использованием современных системных фреймворков (`CoreAudio`, `Network.framework`, `ScriptingBridge`, `ServiceManagement`).
* **Сторожевой сервис `MusicAppLifecycleManager`**: автоматический мониторинг стабильности Music.app и скриптового моста с бесшовным восстановлением состояния.
* Автономный бинарник **Universal 2** (`arm64` Apple Silicon + `x86_64` Intel).
* Работает в строке меню macOS: статус Music.app, быстрый выбор аудиоустройства, частоты ЦАП, меню системных настроек и отображение QR-кода для мгновенного подключения смартфона.
* Автозапуск при входе в систему (Launch at Login).

## 🚀 Установка

### Готовая сборка (DMG)
1. Перейдите на страницу [Релизов](https://github.com/1orgar/amr/releases).
2. Скачайте образ `AppleMusicRemoteMac-Universal.dmg`.
3. Откройте образ и перетащите `Apple Music Remote.app` в папку `Программы` (`/Applications`).
4. Запустите приложение. В строке меню появится иконка 🎵.
5. При первом запуске разрешите приложению управлять `Music.app` в диалоговом окне «Универсальный доступ / Автоматизация».

## 🛠 Сборка из исходных кодов

### Требования
* macOS 14.0 (Sonoma) или новее
* Xcode 15.0+ или Command Line Tools (`xcrun`)
* Swift 5.9+

### Клонирование репозитория
```bash
git clone https://github.com/1orgar/amr.git
cd amr
```

### Запуск тестов

#### Модульные тесты Swift (262 теста):
```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swift test --package-path AppleMusicRemoteMac
```

#### Сквозные интеграционные тесты Python:
```bash
python3 -m unittest discover -s tests
```

### Сборка приложения для текущего Mac
```bash
./AppleMusicRemoteMac/build_app.sh
```
Готовое приложение появится в папке `AppleMusicRemoteMac/build/AppleMusicRemoteMac.app`.

### Сборка универсального DMG (Intel + Apple Silicon)
```bash
./build_universal_dmg.sh
```
Скрипт скомпилирует бинарники для `arm64` и `x86_64`, объединит их через `lipo`, подпишет код и упакует образ диска `AppleMusicRemoteMac-Universal.dmg`.

## 🔌 API и протоколы

Сервер поднимает HTTP и WebSocket на порту `8080` (настраивается), а также UPnP MediaRenderer на порту `8090`.

### WebSocket протокол (`ws://<mac-ip>:8080`)

Каждое сообщение передаётся в формате JSON:
```json
{
  "action": "play_pause",
  "params": {},
  "id": "req-1"
}
```

#### Доступные действия:
| Действие | Параметры | Описание |
| :--- | :--- | :--- |
| `play` | — | Начать воспроизведение |
| `pause` | — | Приостановить воспроизведение |
| `play_pause` | — | Переключить воспроизведение / паузу |
| `next` | — | Следующий трек |
| `previous` | — | Предыдущий трек |
| `seek` | `{"position": 125.5}` | Перемотка на указанную секунду |
| `set_volume` | `{"volume": 80}` | Установка громкости (0–100%) |
| `set_lock_volume_100` | `{"enabled": true}` | Включение/выключение фиксации 100% громкости |
| `set_shuffle` | `{"enabled": true}` | Включение/выключение случайного порядка |
| `set_repeat` | `{"mode": "off"\|"one"\|"all"}` | Режим повтора треков |
| `favorite` | — | Переключение отметки «Избранное» для текущего трека |
| `play_station` | `{"type": "track"\|"artist", "title": "...", "artist": "..."}` | Запуск персональной станции Apple Music |
| `search_and_play` | `{"query": "Depeche Mode"}` | Поиск и немедленный запуск трека/альбома |
| `get_queue` | — | Запрос текущей очереди треков |
| `get_playlists` | — | Запрос списка плейлистов медиатеки |

### HTTP REST API

* `GET /api/status` — текущий статус плеера (`PlayerStatus` в JSON).
* `POST /api/media` — отправка команд управления (`endpoint` и `params`).
* `POST /api/duck` — временное приглушение звука (для Home Assistant TTS).
* `POST /api/unduck` — восстановление исходной громкости.
* `GET /api/artwork/track?id=...` — получение обложки трека в оригинальном качестве.
